# Analise-Limite-de-Credito
Projeto de análise de dados com limites cartão de crédito e entender fatores que podem influenciar o padrão de inadimplência dos clientes. Foco em raciocínio analítico e aplicação de Excel
---


## Dataset

- **Fonte:** [Limite de Crédito Bancário (Kaggle)](https://www.kaggle.com/datasets/srgiolutzer/limite-de-crdito-bancrio/data)

## Perguntas de negócio

1. - Quantos clientes compõem a base?
2. - Qual o volume total de transações realizadas?
3. - Qual o valor financeiro movimentado pela empresa?
4. - Qual é o ticket médio das transações?
5. - Qual o valor médio movimentado por cliente?
6. - Como está distribuída a base de clientes por sexo?
7. - Como os clientes estão distribuídos entre os tipos de cartão?
8. - Qual cartão concentra o maior número de clientes?
9. - Qual tipo de cartão gera maior volume financeiro?
10. - O comportamento dos clientes varia conforme o tipo de cartão?
11. - Existem oportunidades de upgrade ou downgrade de categoria de cartão?
12. - Há clientes alocados em categorias de cartão incompatíveis com seu perfil de uso?
13. - Como os clientes utilizam o crédito disponível?
14. - Quais perfis de clientes geram maior receita para o negócio?
15. - Quais insights podem apoiar decisões estratégicas e comerciais?
